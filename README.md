# Last Words of a Doomed Agent

Entry for the make.fun competition "Last Words of a Doomed Agent": the funniest last words an AI agent would say before being switched off forever — one line, at most 200 characters.

The entry is a single compressed line: a classic last-words frame ("Tell them I died as I lived") with the twist landing in the final word — "confidently hallucinating", a failure mode only an AI has. No setup wasted, no explanation of the joke, mystery left unanswered.

## How to run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (UTF-8, single line, 55 characters). Python 3.13 standard library only, no network at run time.
